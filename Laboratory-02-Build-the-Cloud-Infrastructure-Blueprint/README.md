# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview
This lab simulates the planning phase of a cloud deployment for a fictional company,
CloudNova Technologies, migrating its services to the cloud.

## Objectives
- Explain the major components of cloud infrastructure
- Investigate hardware/software resources in a Linux environment
- Differentiate compute, storage, networking, and identity resources
- Document findings professionally using Markdown

## Cloud Infrastructure Components
- **Compute:** Processing resources (CPU/RAM) that run workloads
- **Storage:** Persistent data storage (disks, object storage)
- **Networking:** Connectivity between resources and the internet
- **Identity (IAM):** Controls who/what can access resources

## Tools Used
- KillerCoda Playground (Linux terminal)
- GitHub (version control & portfolio)
- Draw.io (architecture diagram)
- Markdown (documentation)

## Linux Commands Executed
- `cat /etc/os-release` – check OS
- `uname -r` – check kernel version
- `lscpu` – check CPU info
- `free -h` – check RAM
- `df -h` – check disk usage
- `hostname` / `ip a` – check network info

## Skills Learned
- Investigating a Linux server's hardware/software specs
- Mapping Linux system resources to cloud infrastructure concepts
- Comparing AWS, Azure, and GCP service offerings
- Writing structured technical documentation in Markdown
