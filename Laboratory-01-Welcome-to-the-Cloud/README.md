# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview
Brief summary of the onboarding mission as a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux OS
- Gather basic system information
- Organize files and directories
- Create a GitHub portfolio repository
- Document work using Markdown

## Activities Performed
1. Launched an Ubuntu playground on KillerCoda
2. Created a new sudo user and logged in
3. Gathered system information (distro, kernel, CPU, memory, disk)
4. Built a folder structure (Documents, Notes, Reports, Screenshots)
5. Created and populated markdown documentation files
6. Set up a GitHub portfolio repository

## Linux Commands Used
- `adduser`, `usermod`, `su`
- `whoami`, `pwd`, `hostname`
- `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
- `mkdir`, `ls`, `nano`, `touch`, `cat`

## Skills Learned
Reflect briefly — e.g. basic Linux navigation, user/permission management, markdown documentation, Git/GitHub basics.
